MONOcheck 学習管理 v98

カテゴリ同期の再修正版です。

今回の重要修正:
- PC/スマホで同じカテゴリ名を同じ共通IDへ統一
- 同期時、リモート予定を先に正規化してカテゴリを未設定化してしまう順序バグを修正
- 先に採用するカテゴリ設定を決定し、そのカテゴリ設定を使って予定のカテゴリIDを正規化
- 「その他」カテゴリを廃止
- 旧「その他」や不明カテゴリは登録カテゴリとして復活させず、カテゴリ未設定として扱う
- Service Worker / JavaScript キャッシュ番号をv98へ更新

更新後はPC・スマホの両方で強制再読み込み、またはPWAを完全終了して再起動してください。
