MONOcheck 学習管理 v100

カテゴリ同期の根本修正版。

修正点:
- PC/スマホのカテゴリ設定を片方だけで上書きしない
- localStorage側とクラウド側の「元のカテゴリID」を両方残してから正規化
- 同名カテゴリは共通IDへ統合
- 片方の端末にしか存在しないカテゴリを使う予定も未設定へ落とさない
- 「その他」はカテゴリとして登録しない
- キャッシュバージョンを更新

重要:
PC・スマホともこのv100を読み込んでから同期してください。
既にv99までの同期で予定のcatが空文字へ変換されてしまった予定は、空文字になった時点で元IDが失われているため自動復元できません。その場合は、カテゴリ設定を選び直して保存してください。
