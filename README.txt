# MONOcheck 学習管理 — キャッシュ自動更新版

今回の修正：
- Service Worker のキャッシュをバージョン管理
- 新しい Service Worker を即時有効化
- 古いキャッシュを自動削除
- index.html / sync.js / 設定ファイル / JSON はネットワーク優先
- Service Worker 自体の更新確認を自動実行
- 更新が反映されたらページを自動リロード（ユーザーによる強制再読み込み不要）

使い方：
1. このフォルダ一式を、今使っている Render の公開フォルダへ置き換える
2. Render のデプロイ完了を待つ
3. 通常どおりアプリを開く

※初回の更新時だけ、ブラウザ側が新しい Service Worker を認識するまで少し時間がかかる場合があります。
