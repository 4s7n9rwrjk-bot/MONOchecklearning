# MONOcheck 学習管理 — スマホPWA同期対策版 v2

今回の重要修正
- ログイン直後にスマホ側の古いデータでクラウドを強制上書きしない
- 保存時も毎回「強制上書き」せず、端末とクラウドの更新時刻を比較
- 同期中に数値を変更した場合、その変更を捨てず、同期完了後にもう一度同期
- PWAのService Workerを更新

Renderへこのフォルダの中身を上書きデプロイしてください。

確認手順
1. PCとスマホの両方で同じアカウントにログイン
2. PCで数値を変更して保存
3. スマホのPWAを開いて確認
4. スマホ側で別の数値を変更
5. PC側を開いて変更が反映されるか確認

※ 同じアカウントを使っていることが前提です。
