MONOcheck 学習管理 v97

今回の修正:
- PCとスマホでカテゴリIDが別々になる問題を修正。カテゴリ名から安定した共通IDを生成し、同じカテゴリは同じIDとして同期します。
- 既存の cat_xxx / legacy_xxx 形式のカテゴリも同期時に共通IDへ移行します。
- 「その他」カテゴリを廃止。既存の「その他」や不明なカテゴリは「未設定」として扱い、カテゴリ一覧には表示しません。
- カテゴリ削除時も既存予定は「その他」へ移さず、カテゴリ未設定にします。
- PC/スマホ双方のクラウド同期前にカテゴリを正規化します。
- Service Workerのキャッシュ識別子をv97へ更新。

Renderへ上書き後、PC/スマホ双方で一度再読み込みしてください。
同じカテゴリ名が双方に存在する場合、次回同期から共通カテゴリとして扱われます。
