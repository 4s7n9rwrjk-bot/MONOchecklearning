MONOcheck 学習管理・家族閲覧モード追加版

■ 追加機能
本人は従来どおりメールアドレス＋パスワードでログインし、PC・スマホから編集・同期します。
家族などは同じMONOcheckの「👁 閲覧する」から、本人が設定した閲覧ID＋閲覧パスワードで入れます。
閲覧モードでは学習・目次・日別記録・レポート準備・予定管理カレンダーなどのデータを確認できます。
追加・編集・削除などの操作はできません。

■ 閲覧データの更新
閲覧画面は10秒ごとにSupabaseから最新データを確認します。
本人がPC・スマホで変更して同期すると、閲覧画面にも自動反映されます。

■ 初回設定
1. 本人アカウントでログイン
2. 「☁ 同期」を開く
3. 「閲覧ID」「閲覧パスワード」を設定
4. 家族側で同じMONOcheckを開き、「👁 閲覧する」から設定したID/パスワードで入る

■ Supabase側の追加設定（必須）
viewer_schema.sql をSupabase SQL Editorで1回実行してください。
このSQLは既存の monocheck_study_data を変更せず、閲覧用テーブル・RPCだけを追加します。

■ セキュリティ
閲覧パスワードはデータベースに平文保存せず、pgcryptoのcrypt()でハッシュ化します。
閲覧側には一時的な30日有効の閲覧セッショントークンを保存します。

■ 既存機能
既存のPC・スマホ同期、学習データ、予定、グラフ、カレンダーのデータ構造はそのまま利用します。
